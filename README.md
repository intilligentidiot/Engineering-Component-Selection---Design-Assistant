# Tesla Mechanical Designs — Motor & Gearbox Engineering Selection Tool

An engineering decision-support platform to help engineers select suitable motors and gearboxes based on engineering requirements.

## Stack
- Python + FastAPI
- SQLite + SQLAlchemy
- HTML + CSS + Vanilla JS
- Pytest

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   uvicorn app.main:app --reload
   ```

3. Run tests:
   ```bash
   pytest
   ```
